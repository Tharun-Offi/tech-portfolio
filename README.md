# 🚀 Tharun Murugavel — 3D Interactive Developer Portfolio

An ultra-modern, high-performance **3D Developer Portfolio** engineered with React, Three.js / React Three Fiber, Framer Motion, and Tailwind CSS. Built using complete career and academic information from [tharun-murugavel.netlify.app](https://tharun-murugavel.netlify.app).

---

## 🌟 Key Highlights & Features

### 🌌 1. 3D WebGL Experiences
- **Interactive Holographic Hero Scene**: Real-time distorted WebGL energy sphere, rotating wireframe octahedron, and dual glowing orbital rings that dynamically react to mouse tracking and hover.
- **Interactive 3D Tech Sphere / Cloud**: 3D interactive particle cloud displaying technologies (Python, React, Three.js, MySQL, Embedded C, Flask, Java, etc.) which can be rotated and dragged in real-time 3D space.
- **Global 3D Cosmic Particle Starfield**: 1200+ particle constellation points dynamically floating across the background.

### 💻 2. Interactive Retro-Cyber CLI Terminal
- Built-in terminal emulator with interactive command execution:
  - `skills` — Full-stack & 3D tech competencies
  - `projects` — Interactive project list with direct GitHub links
  - `experience` — TCS (Assistant System Engineer Trainee) & Expleo (SiL Server Intern)
  - `education` — B.E. Computer Science (CGPA 8.11) & Schooling
  - `contact` — Direct channels (Email, WhatsApp, LinkedIn, GitHub)
  - `sudo hire` — Triggers celebratory confetti animation!
  - `clear` — Clear command logs

### 🃏 3. 3D Perspective Tilt Project Cards
- Mouse-tracking dynamic 3D angle tilt with realistic glare sheen and depth parallax.
- Category filters: *All Projects*, *Web & VR*, *Machine Learning*, *Systems & IoT*.
- Click-to-open **Project Modal** with comprehensive architecture breakdown and metrics.

### ⚡ 4. Professional Experience & Education Roadmap
- Circuit neon timeline for **Tata Consultancy Services** (TCS) and **Expleo Solutions**.
- Academic milestone cards for **Erode Sengunthar Engineering College** (8.11 CGPA), **S.D. Eaden Matriculation** (84.34%), and **St. Paul Matriculation**.

### 📬 5. Say Hello & Contact Hub
- Integrated with Web3Forms API + instant copy-to-clipboard for email and phone.
- Instant WhatsApp direct chat trigger.
- Embedded stylized dark-mode map of Kurinjipadi, Tamil Nadu, India.
- Dynamic Indian Standard Time (IST) live clock in the footer.

### 📄 6. Printable / Interactive Resume Modal
- Pop-up formatted resume view with clean print-to-PDF support (`Ctrl + P` / `Cmd + P`).

### 🔊 7. Web Audio Synthesizer
- Built-in lightweight sci-fi audio feedback on clicks and hovers with a global mute toggle.

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Vite
- **3D Graphics / WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: Framer Motion
- **Styling**: Tailwind CSS (Dark Cyber Aesthetics, Glassmorphism, Mesh Gradients)
- **Icons**: Lucide React + Custom SVG Brand Badges
- **Effects**: Canvas Confetti, Web Audio API

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
```bash
# 1. Install all dependencies
npm install

# 2. Run the development server
npm run dev
```

The portfolio will be live at `http://localhost:3000`.

### Production Build
```bash
# Compile TypeScript & bundle with Vite
npm run build

# Preview the production build locally
npm run preview
```
